# Hanken Grotesk

The landing page and social preview use the Latin variable WOFF2 from [Google Fonts](https://fonts.google.com/specimen/Hanken+Grotesk), served locally to avoid third-party font requests. The font is licensed under the [SIL Open Font License](OFL.txt).

Source file: [Hanken Grotesk, Google Fonts v12](https://fonts.gstatic.com/s/hankengrotesk/v12/ieVn2YZDLWuGJpnzaiwFXS9tYtpd59CxCis4.woff2).

# Headings

Headings on the landing page and social preview use Arial, Helvetica and the browser sans-serif fallback, matching the README title assets.
